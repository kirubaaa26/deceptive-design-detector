 Deceptive Design Detector

An interactive web application built to audit user interface (UI) copy and checkout flows for deceptive design patterns (dark patterns). Designed with a focus on human-computer interaction (HCI) and user autonomy, this tool evaluates deceptive practices using a severity-weighted scoring system.

 Features

-Semantic Intent Analysis:** Audits short UI copy, checkout statements, and descriptive narrative reviews for manipulative phrasing.
Severity-Weighted Scoring Model:** Starts from a 100-point ethical usability base and deducts points based on UX harm severity:
-30 pts (High Severity):** Obstruction, Hard to Cancel / Forced Continuity, Bait-and-Switch
-25 pts (Medium Severity):** Sneaking / Unconsented Add-ons
-15 pts (Low Severity):** Fake Urgency, Confirmshaming
- Actionable Remediation Guidelines:** Provides immediate recommendations on how to redesign the interface ethically.
- Clean, Aesthetic UI:** Built with custom typography (Poppins & Inter) and a streamlined, responsive layout.

 Tech Stack

- Python (Core logic and text processing)
- Streamlit (Interactive web application framework)
- Custom CSS(Typography and layout styling)
